## Features
- Sticky header with scroll-triggered background blur
- Dark / light mode toggle (persists via JS)
- Smooth scroll navigation
- AOS (Animate On Scroll) animations throughout
- Responsive two-column layout (CSS Grid)
- Contact/join form with custom radio button styling
- Gear shop section with product cards
- Google Maps embed for location
- Responsive footer with 4-column grid

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (scroll events, dark mode toggle, back-to-top button)
- [AOS Library](https://michalsnik.github.io/aos/) for scroll animations

## What I Learned
- How to structure a real multi-section single-page website
- CSS Grid for responsive layouts that adapt from mobile to desktop
- Making a sticky header that changes style on scroll using JavaScript
- Implementing dark mode with a class toggle on the body element
- Styling custom form inputs (radio buttons with CSS `::before` pseudo-elements)
- Working with external libraries via CDN

## How to Run Locally
1. Clone the repo: `git clone https://github.com/sesethumngxozana-ui/boulder-inc-website`
2. Open `index.html` in your browser — no build step needed
